# Lamora Flower

Website bán hoa lụa **Lamora Flower**: web cho khách và trang quản trị cho chủ shop, trong một dự án Next.js.

> Tài liệu thiết kế nằm trong thư mục [`docs/`](docs/00-MASTER-PLAN.md). Quy tắc làm việc với AI nằm trong [`AGENTS.md`](AGENTS.md).

## Cần có trên máy

- **Node.js 22** (xem `.nvmrc`)
- **pnpm** (`npm install -g pnpm`)
- **Git**

## Chạy thử trên máy

```bash
pnpm install
pnpm dev
```

Mở http://localhost:3000 để xem.

## Lệnh thường dùng

| Lệnh | Việc |
|---|---|
| `pnpm dev` | Chạy local |
| `pnpm lint` | Kiểm tra quy tắc code |
| `pnpm typecheck` | Kiểm tra kiểu dữ liệu |
| `pnpm build` | Build thử bản chạy thật |

Danh sách lệnh đầy đủ và lộ trình các bước: xem `AGENTS.md` (mục 4 và mục 10).
